Data & limits

  • Wind forecast · Open-Meteo (no API key). Hourly speed, gusts, and direction for planning.
  • Tides · Marine API where available; used for launch windows you set per spot.
  • Kite ranges · Manufacturer catalog bands, adjusted for rider weight and ability. Guidelines only.
  • Calibration · Your logged sessions under Riders → Calibration tweak scores near similar wind.

Nothing here replaces local knowledge, club advice, or your own judgment. Offshore detection uses the sectors you configure on each spot, not automatic coastline analysis.
